Patches of color are placed on a canvas according to simple rules.

Forms inspired by Whanki Kim, title from a poem by Christopher Knowles in Einstein on the Beach.

Algorithmic and selected colors. p5js.

This is a program, not a picture: each load draws a new variation from a random seed. Originally minted on fxhash. The code here is byte-identical to the original on IPFS (QmPPhFiURxQs2yfeQiKtfsXY1f85nPBapgKJt3wEfa5M5R).
